# DDIA Book 项目记忆

## 项目概述
- 基于 docsify 的 DDIA 逐章精读在线书籍
- 中文编写，使用 GitHub Pages 托管
- 仓库地址: https://github.com/DistSysCorp/ddia
- 侧边栏文件: `_sidebar.md`，控制目录结构

## 文件结构
- `ch01.md` ~ `ch11.md`：十一章精读笔记
- `ch01-supplement.md` ~ `ch11-supplement.md`：各章补充材料（2026-09-19 新增）
- `preface.md`：序言
- `index.html`：docsify 入口
- `img/`：图片资源
- `js/`、`css/`：前端资源

## 补充材料内容
每章补充材料包含三部分：
1. 核心概念深化：对原章概念的深入解释
2. 2026年工业界最新进展：最新技术趋势
3. 经典论文与最新论文推荐（2023-2026）
